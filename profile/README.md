# Gesund-Score

**Lebensmittel transparent einordnen.** Gesund-Score bewertet Produkte mit einem
nachvollziehbaren Score von 0–100 und zeigt die entscheidenden Faktoren,
Nährwerte, Quellen und den Vergleich innerhalb der Kategorie.

🌐 [gesund-score.de](https://gesund-score.de)

Der Score ist eine Orientierung und ersetzt keine Ernährungs- oder medizinische Beratung.
